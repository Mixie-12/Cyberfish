What is a DeKoi?

Successful cyber attacks are increasing due to AI making weaknesses faster to exploit.

A DeKoi uses a Raspberry Pi to pose as a decoy for intruders on your network. The application sends a notification to your phone if someone touches the honeypot.

Click to learn more
Raspberry Pi 4 Model B

DeKoi is built to be attacked, safely

  • The box only connects outward. Nothing can connect in.
  • No passwords, no remote login, no web interface on the box.
  • The password an attacker types never leaves the box.
  • It only installs updates signed with our key.
  • Data stays in the EU for 90 days, and each owner sees only their own events.

DeKoi was made during the Oslo Sprint 2026 Hackathon by team CyberFish.
